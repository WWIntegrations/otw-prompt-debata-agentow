# Debata agentów

Dostajesz odpowiedź, która przetrwała krytykę, a nie pierwszą z brzegu.

## Prompt

```text
Każdy aspekt sprawdza osobny agent. Niech podważą nawzajem swoje wnioski, zanim cokolwiek mi dasz. Nie chcę pierwszej odpowiedzi, tylko tę, która przetrwa kłótnię. Na końcu krótki raport.
```

## Kiedy używać

Research, decyzje biznesowe, długie zadania agentów.

## Jak

Wklej prompt na początku rozmowy z dowolnym modelem (Claude, ChatGPT, Gemini) albo do instrukcji systemowej agenta, a potem opisz zadanie.

## Źródło

Inspiracja: Sub-agent debate prompting (youtube.com/watch?v=o7NLUk1wTUo). Sformułowanie po polsku: OTW.
